The standards this tool measures against

These are the numbers every measured finding is compared with. They are settings rather than constants because a threshold nobody can change is one people work around — if the first response target moves, change it here rather than waiting for a new build.

The team

The agents the coaching sheet has a row for, one per line. A name here is matched against the case owner Salesforce reports, so it wants to be the name as Salesforce writes it. An agent who turns up in the queue but is not on this list still gets reviewed and still gets a coaching row — the list decides the ORDER of the sheet and who appears on it with no cases yet, not who may be reviewed.

How many cases at once

Each case is opened in a background window, read to the end of its feed and closed again. More at once is faster and heavier: every case being read is a full Salesforce page in memory. Two is comfortable on a support laptop; go higher only if the machine has room, and expect the reader window to surface more often.

The AI

Reviews are written through the Microsoft 365 Copilot relay: the tool drives a Copilot tab in a window of its own, the same way the SOTI AI Analyser does, so no case data goes anywhere the browser was not already signed in to. Chrome has to grant access to that site once — press Grant below and allow it when asked.

Updates

The button beside the version number asks GitHub what has been published and shows a dot when it is newer than this build. It needs permission to reach api.github.com, which Chrome asks for the first time you press it — that host is used for the version check and nothing else, and the download itself goes through Chrome's own downloads rather than through this page.
